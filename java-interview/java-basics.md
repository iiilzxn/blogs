# Java 基础面试题

## 1. 面向对象三大特性？

封装、继承、多态。

- **封装**：隐藏内部实现，对外暴露接口
- **继承**：子类复用父类代码，extends
- **多态**：同一个方法不同表现，重载和重写

## 2. == 和 equals 区别？

- `==` 比较栈中的值。基本类型比较值，引用类型比较地址
- `equals` 默认也是 `==`，但 String 等类重写了它，比较内容

## 3. String、StringBuilder、StringBuffer？

| | String | StringBuilder | StringBuffer |
|------|--------|-------------|-------------|
| 可变性 | 不可变 | 可变 | 可变 |
| 线程安全 | - | 不安全 | 安全(synchronized) |
| 性能 | - | 快 | 慢 |
